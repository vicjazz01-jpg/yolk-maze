# 蛋黃大冒險

手機優先的迷宮追逐遊戲。帶小蛋黃吃光迷宮裡的芝麻與金黃能量球，避開莓醬、抹茶、紫芋和牛奶。迷宮、角色名稱、美術與圖示都是為本遊戲原創。

## 怎麼玩

- 在迷宮上滑動，或按下螢幕下方的方向鍵。電腦可用方向鍵或 W、A、S、D。
- 吃芝麻得 10 分，吃能量球得 50 分。能量持續期間，可以反吃變成藍紫色的追兵，連吃分數依序為 200、400、800 和 1,600 分。被反吃的追兵會回到草窩，等能量消退才出來。
- 左右兩側的隧道相通，小蛋黃和追兵都能穿過。清空迷宮後進入下一關，移動速度會逐步提高。
- 每場有三條命。按「暫停」可繼續遊戲或返回首頁，電腦也可按 Esc 或 P 暫停。最高分存在目前使用的瀏覽器中。

## 開啟遊戲

直接用瀏覽器開啟 `index.html` 即可遊玩。本機要測試離線安裝時，可在此目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000/`。也可以將檔案原樣部署到支援 HTTPS 的靜態網站，例如 GitHub Pages 的專案子路徑。遊戲免安裝套件、免編譯。

## 加到 iPhone 主畫面

1. 用 Safari 開啟遊戲的 HTTPS 網址，等首頁載入完成。
2. 點分享按鈕，選擇「加入主畫面」。
3. 點「新增」，日後可從主畫面的蛋黃圖示進入。第一次載入完並完成離線快取後，就能離線遊玩。

若從主畫面開啟後仍看到舊版，請完全關閉遊戲，再從主畫面開啟一次。

## 重新產生圖示

在已安裝 Pillow 的環境執行 `python3 generate-icons.py`，會更新 `icons/` 裡的三個 PNG。部署更新時，請同步更新 `service-worker.js` 中的快取版本。
